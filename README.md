##Project Description

This project entails creating a website for the Wanjiku Gatonye Foundation.The website will showcase the charity works and activities that the foundation is involved in. More importantly, it offers a seamless way for volunteers to join WGF as well as make donations towards its causes. In addition, volunteers and interested persons will be able to access annual reports from the foundation, all the click of a button,

The system's donation management, coupled with its logic functions will be based on a non-relational database. We shall also have a database server that supports thousands of users as projected in the near future, while providing a great user experience.

##Project Context
The WGF website is a three months' long project that we set out to build with two key focal points:
1. The ability for volunteers to donate to the foundation as well as join in its activities.
2. A web-based admin system for easy access and updating of the foundation's data. It is also here that the foundation's annual reports will be managed, and donations monitored.

The system database will store, among others, the foundation details, donation & payment details and yearly reports. 

With its online payment options, volunteers should be able to donate using Visa and Mastercard (internationally), as well as through MPESA (locally). System support will also be available for registered volunteers who may need assistance while using the website. 

One of the constraints we faced was the implementation of the database, particulalry using a centralized database management system.

###Technologies used for this project

####Front-end
For the Front-end, we are using ReactJS and NGINX

####Back-end
For the back-end, we will be using ExpressJS, NodeJS and NGINX. Both the front-end and back-end make use of Javascript(ReactJS, ExpressJS & NodeJS) for their dynamic functionality and interactiveness.

####Database
We chose the MongoDB database to save records (user details, payments and transactions) because it is speedy, reliable and scalable. Additionally, MongoDB also supports data encryption and this is key to maintaining a secure system.

####Operating system
Our operating system of choice is the Ubuntu OS because it has excellent support and server-friendliness.

##Roadmap/ideas for the future
As the foundation grows, we envision that more data will be stored in the database and have made provisions for the same as this is a scalable product.
